# 01 — Goals and user journey

Primary goal: getting hired for mid-level digital marketing and web/digital operations roles. Secondary: appropriate freelance design/website/marketing inquiries. Shared identity: digital marketing, web operations and design, connected by hands-on implementation and measurement. Don't position TJ solely as graphic designer.

Desired impressions: visually impressed -> knows TJ and his disciplines -> sees approachable skilled person -> understands verified experience/outcomes -> sees design craft -> explores actual work -> learns more about TJ -> contacts him. These are design intentions, not promises about user reactions.

Support fast evaluators and curious explorers. Work/resume/contact always directly accessible without animation. No mandatory sequence or choose-employer/client gate.

Homepage sequence:
1. Integrated editorial hero: visual impact, identity, human presence, embedded destinations.
2. Selected work: 2–3 strong substantive preview slots, not a dump of all projects.
3. Experience/credibility: real scope, duration and results where supplied; distinguish outcomes from responsibility.
4. Concise personal introduction: approach/background, portrait if useful, About route.
5. Contact invitation: actual methods and accurate availability if supplied.

Avoid repeating the same generic claims in each section. Work previews need problem, TJ's contribution and actual evidence or clearly provisional draft. Missing metrics never justify fake stats. One substantial professional role is valid: show sustained scope, not invented employer variety.
