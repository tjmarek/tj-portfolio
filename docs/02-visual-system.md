# 02 — Visual system

## Current design direction
Portrait-led editorial cover, integrated page destinations, bold compact name bridging portrait/work regions, generous breathing room. Strong color surfaces, quiet functional labels. Not generic two-column sales hero; not a collection of cards. Refine one composition rather than combine unrelated decorative ideas.

## Brand color candidates carried into current mockup direction
Use this approved-for-draft Sage/Charcoal/Red family consistently. No need to force all colors onto every section.
--base #E5EBE5; --surface #F4F7F4; --border #C2D1C2; --charcoal #262626; --dark-sage #4A5B4E; --red #DD2713; --red-hover #B81F0E; --on-red #FEFEFE.
Sage portrait area, Charcoal work area, Red logo/selected-row detail. Strong brand does not mean decorative red wedges or giant red gradients. Exact user logo colors may vary; document discrepancy, preserve original.

Opaque contrast examples: Charcoal/Base 12.50; Dark Sage/Base 5.99; White/Red 4.76; White/Hover Red 6.43; Red/Base 3.97; Red/Surface 4.448; Border/Base 1.32; Red/Dark Sage 1.51. Normal text >=4.5; large >=3 (24px regular or ~18.7px bold); essential UI generally >=3 against actual surfaces. Bold alone is insufficient. Don't round a failing ratio up. Primary Red not small text on light/dark backgrounds indiscriminately. Border decorative only. Verify actual glass/background states separately.

Portrait photography is exempt from restricted flat UI colors. Real project imagery needs permission; no fake branded screenshots. Avoid unauthorized recoloring of actual work.

## Typography
Prior Bricolage Grotesque display, Manrope UI/body and Syne 700 wordmark are AVAILABLE CANDIDATES, not an obligation to use three fonts. Default first draft: Bricolage display/name and Manrope UI/body; Syne only if actual wordmark lockup is supplied/needed. Prefer cohesive two-family system. No extra serif work heading plus oversized italic plus multiple display voices. If using italic name use actual supported italic or controlled deliberate treatment, not accidental synthetic distortion. Keep essential name readable.
Body near 18px and comfortable line height; small labels legible, not tiny decoration. License and self-host appropriate WOFF2 if feasible; preserve licenses. Real fallback if fonts unavailable.

## Material choice: frosted, not liquid lens
Only contact cluster receives restrained Sage-tinted frosted glass: translucent fill with enough opacity, modest backdrop blur, very subtle glossy rim and depth. No wobble, refraction, thick inflated bubble, giant transparent cards, heavy shadows or glass behind work/name/face. About corner mostly solid. Glass is finish, not concept. At rest it must look complete. Solid fallback for unsupported backdrop-filter and reduced-transparency preference where available; text always readable. Don't assume blur guarantees contrast.
